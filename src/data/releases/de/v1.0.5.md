## Verbesserungen

- Gesichtsveredelung läuft standardmäßig auf Front und Seite virtuelle Anprobe Die App findet den Kopf auf dem Gerät, fordert das Bildmodell auf, eine Nahaufnahme zu verfeinern, und richtet und fügt das neue Gesicht in das Originalbild ein. Haare, Kleidung und Hintergrund bleiben erhalten. Das Original bleibt erhalten, wenn die Erkennung oder Verfeinerung fehlschlägt oder sich der Winkel ändert.
- Jede verfeinerte Ansicht verwendet eine zusätzliche Bildanforderung. Die virtuelle Anprobe-Schätzung enthält sie, und die Option kann unter Ansichten deaktiviert werden, um sie zu generieren.
- Seiten- und Rückseitenreferenzen lassen den Kopf weg, wenn eine Pose fehlt und Hüte oder Zubehör es nicht brauchen. Wenn Referenzschlitze es zulassen, verwendet die Seitengeneration auch das ursprüngliche Frontbild des Modells zur Identität.

## Fixes

- Ein unerreichbarer Server meldet nun einen Verbindungsfehler, im Unterschied zu einem Anforderungs-Timeout.
- HTTP 499 von einem Gateway wird als Serverunterbrechung behandelt.
- Anforderungsprotokolle erfassen den Status, die Details und die verstrichene Zeit für jeden fehlgeschlagenen Versuch.

Regenerieren Sie das seitliche Modellbild oder alle Ansichten und vergleichen Sie die neuen virtuelle Anprobe-Ergebnisse.
