# v1.0.15 修訂 1

- 分類統一到每個單品：移除資訊頁重複類別欄和試穿分類設定，照片類別自動由單品彙總。新增髮箍、髮夾、髮圈、襪子等分類，支援配飾父類篩選。
- 搜尋按單品標題、描述、分類和屬性建立文件，支援髮箍/頭箍/headband別名，避免同一照片的顏色屬性串到其他單品。結果顯示命中的單品及區域性預覽，點選直達單品詳情。
- 鍵盤搜尋保留原始輸入；AI理解改為可選篩選建議，應用後才生效。向量暫不可用時保留本地文字結果，編輯後更新單品索引。
- 試穿記錄逐件顯示實際選中的衣物名稱、區域性圖與順序，生成時凍結選件資訊；單品詳情只試穿該單品，整套詳情明確顯示“試穿整套”。
- 多配飾使用獨立佩戴位置、數量、身體側和覆蓋範圍；正側背共用同一模特基準，固定髮型和襪子狀態，仍保持一次試穿生成，不新增人物修補輪次。
- 舊資料平滑升級；刪除原衣物後，仍被試穿歷史引用的圖片繼續保留。

應用顯示版本為1.0.15，修訂包使用獨立的v1.0.15-r1釋出標識和更高versionCode，保留原版下載。舊資料沒有的單品屬性和佩戴細節可以重新識別或手動補充，升級不自動呼叫收費識別。
