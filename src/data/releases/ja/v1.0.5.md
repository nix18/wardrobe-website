## 改善点

- 顔の洗練は、前面と側面のバーチャル試着とサイドモデルビューのデフォルトで実行されます。このアプリは、デバイス上のヘッドを見つけ、画像モデルはクローズアップを絞り、新しい顔を元の画像に合わせ、ブレンドするように要求します。髪、衣服、背景が保存されます。元のものは、検出または精製が失敗したり、角度が変化したときに保持されます。
- 各洗練されたビューは、余分な画像リクエストを使用します。 バーチャル試着 の見積もりには、それが含まれています。オプションは、ビューの下をオフにして生成できます。 タスクの割り当て下にある別のプロバイダを割り当てるか、プロンプトテンプレートを編集します。
- サイドとバックはポーズが不在で帽子やアクセサリーが不要なときに頭を省略します。参照スロットが許可されると、サイド生成はモデルの元の正面イメージをアイデンティティに使用しています。

## フィックス

- 到達不能なサーバーは、リクエストタイムアウトとは異なる接続障害を報告します。
- ゲートウェイから HTTP 499 は、サーバーの中断として扱われます。 タイムアウトのリトライ設定は、それがリトリーズかどうかを制御します。
- リクエストログは、失敗した試みごとにステータス、詳細、および経過時間を記録します。

サイドモデルのイメージやすべてのビューを再生し、新しいバーチャル試着結果を比較します。
