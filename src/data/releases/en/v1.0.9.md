## Fixes

- Release builds now retain the pose detection components required to create a pose from a photo. This also restores face refinement, tone matching, and reuse of the model’s face in try-on images. Detection runs on the CPU.
- Generation runs in a foreground service so switching apps or locking the screen does not normally interrupt it. A notification shows active generation and queued tasks when notifications are permitted.
- On phones with aggressive battery management, Wardrobe links to the system setting to allow background activity. Time spent suspended is excluded from the request timeout, so completed responses can be read when you return.
