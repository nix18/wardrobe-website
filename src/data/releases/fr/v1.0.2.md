## Améliorations

- La génération de modèles, le prétraitement photo, les vues latérales et dorsales, et essayage virtuel utilisent maintenant un éclairage doux, même, semblable à une journée nuageuse brillante ou une grande boîte à softbox frontale avec remplissage.
- Essayage virtuel maintient l'éclairage plus doux même lorsque l'image de référence du modèle a une lumière plus dure.

Régénérer les images de modèles pour utiliser le nouvel éclairage dans le futur essayage virtuel. Les modèles personnalisés restent actifs. Restaurer les valeurs par défaut sous IA Services › Modèles Prompt pour utiliser les nouvelles invites d'éclairage.
