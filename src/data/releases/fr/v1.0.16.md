# v1.0.16

- Wardrobe suit la langue du téléphone et prend en charge le chinois simplifié, le chinois traditionnel, l’anglais, le français, le portugais, l’espagnol, l’allemand et le japonais. L’anglais est utilisé pour les autres langues.
- L’interface, les réglages, la politique de confidentialité, les arrière-plans et les descriptions des poses suivent la langue de l’application. Android 13 ou ultérieur permet de choisir une langue propre à Wardrobe.
- Le site choisit une langue selon la région et mémorise vos préférences. Les README anglais et chinois présentent des captures d’écran à jour.
