## Arreglos

- Los módulos ahora conservan los componentes de detección de poses necesarios para crear una pose de una foto. Esto también restaura el refinamiento facial, el emparejamiento de tono y la reutilización de la cara del modelo en las imágenes de prueba virtual. La detección se ejecuta en la CPU.
- La generación se ejecuta en un servicio de primer nivel, por lo que cambiar aplicaciones o bloquear la pantalla no lo interrumpe normalmente. Una notificación muestra tareas activas de generación y misiones apagadas cuando se permiten notificaciones.
- En los teléfonos con la gestión agresiva de baterías, Wardrobe se vincula con el sistema para permitir la actividad de fondo. El tiempo pasado suspendido se excluye del tiempo de solicitud, por lo que las respuestas completas se pueden leer cuando usted regresa.
