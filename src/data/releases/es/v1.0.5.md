## Mejoras

- El refinamiento facial funciona por defecto en la parte delantera y lateral prueba virtual y las vistas laterales del modelo. La aplicación encuentra la cabeza en el dispositivo, pide al modelo de imagen que refina un cierre, y alinea y mezcla la nueva cara en la imagen original. Se conserva el cabello, la ropa y el fondo. El original se conserva cuando la detección o el refinamiento falla o el cambio de ángulo.
- Cada vista refinada utiliza una solicitud de imagen adicional. La estimación prueba virtual la incluye, y la opción se puede apagar bajo Vistas para generar. Asignar un proveedor separado bajo asignaciones de tareas o editar la plantilla de inicio.
- Las referencias laterales y traseras omiten la cabeza cuando una pose está ausente y los sombreros o accesorios no lo necesitan. Cuando las ranuras de referencia permiten, la generación lateral también utiliza la imagen frontal original del modelo para la identidad.

## Arreglos

- Un servidor inalcanzable informa ahora de un fallo de conexión, distinto de un tiempo de solicitud.
- HTTP 499 de una puerta de entrada se trata como una interrupción del servidor. La preferencia de reingreso de tiempo controla si se reinicia.
- Solicitar registros registrar el estado, los detalles y el tiempo transcurrido para cada intento fallido.
