# v1.0.16

- Wardrobe sigue el idioma del teléfono y admite chino simplificado, chino tradicional, inglés, francés, portugués, español, alemán y japonés. Para los demás idiomas se utiliza el inglés.
- La interfaz, los ajustes, la política de privacidad, los fondos y las descripciones de poses siguen el idioma de la aplicación. En Android 13 o posterior puedes elegir un idioma para Wardrobe en los ajustes del sistema.
- El sitio elige el idioma según la región y recuerda tu elección manual. Los README en inglés y chino incluyen capturas nuevas.
