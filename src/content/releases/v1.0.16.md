# 小衣柜 v1.0.16

- App 跟随手机语言，支持简体中文、繁體中文、英语、法语、葡萄牙语、西班牙语、德语和日语。其他语言回退到英语。
- 主界面、设置、隐私政策、预设背景和动作说明随应用语言显示。Android 13 及以上可在系统设置中单独选择小衣柜的语言。
- 网站按访问地区选择语言，并提供可记住偏好的语言菜单。项目和网站的 README 提供中英文版及更新后的截图。
