# 小衣柜 v1.0.16 修订 1

- 「我的」页新增「语言」，可以在应用内切换八种语言，也可以恢复跟随系统。重启应用后会保留选择。
- 网站首页、功能介绍和截图轮播里的应用截图随网站语言切换，包含相应语言的示例衣物和标签。
- Android 应用仍显示 1.0.16，修订包可覆盖安装在上一版之上。
