Your data, your device

衣柜是你的，数据也是

小衣柜没有自己的服务器。衣物、照片和试穿记录保存在手机里，想在多台设备上用，就同步到你自己的网盘。

本地优先

所有数据默认只在本机。卸载应用即删除全部本地数据；也可以随时导出 zip 备份。

自带 AI 服务

填写你自己的 API Key，加密保存在本机，不会被同步或备份。只有使用 AI 功能时，照片才会发给你选的服务商。

多端同步

谷歌云盘、WebDAV（坚果云、Nextcloud、群晖）、FTP/FTPS。改动后自动在后台同步，换手机登录同一账号即可。

FAQ

常见问题

小衣柜收费吗？

应用免费。AI 识别和生图由你自己配置的服务商按量计费，费用取决于选用的模型；试穿页会提示这次大约调用几次图像模型。

开始使用需要准备什么？

一台 Android 8.0 及以上的手机，以及一个支持图片输入的对话模型（用于识别衣物）。想用 AI 试穿，再添加一个图像生成服务，例如豆包 Seedream 或通义千问图像。

我的照片会被上传吗？

小衣柜没有自己的服务器。照片只在你使用 AI 功能时发给你配置的 AI 服务商；开启云同步后，数据同步到你指定的谷歌云盘、WebDAV 或 FTP。

API Key 安全吗？

API Key 用 Android Keystore 加密保存在本机，不会被同步或备份。换新手机时，在「AI 服务」里重新填写一次即可。

有 iPhone 版吗？

目前只有 Android 版。
