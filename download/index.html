v1.0.13 更新内容

在 GitHub 上查看

新功能

  • 一张照片里有几类衣物也能试穿。整套穿搭、上下装套装这类照片，AI 识别时会给每一件都选上类别（比如上衣、裤装、鞋履），「试穿类别」保持「自动」就会自动勾选这几类；也可以手动多选。
    • 试穿页里这张照片会分别出现在上装、下装等对应的位置，选哪一类就只穿上哪一类，照片里的其他衣服不会被穿到模特身上。
    • 只是展示一件衣物的照片（例如模特身上还穿着别的衣服的商品图）仍只算这一件。
    • 试穿时按选中的那件裁剪；取消自动勾选的某一类即改为手动选择，编辑页也会提示照片里还识别到了哪些可以一并选上。
    • 试穿记录会记下穿的是照片里的哪几类，「重新试穿」时按原样恢复。

修复

  • 打开「一张图同时生成」并选了动作时，背面用错了手、腿。例如「单手扶头」，背面画成了另一只手扶头。现在每个视角的动作说明各写一句，背面的左右与正面相反。
  • 照片动作被改成坐姿，手势、屈膝和前后关系丢失。新建动作会保存来源照片，试穿时直接参考原动作，保留两腿不对称、手指姿势和透视关系，不再用估算骨骼及自动猜测的动作类型代替原图。各视角仍独立生成，也支持一张图同时生成，不增加生图次数。
  • 旧照片动作被误写成坐姿。修正只凭大腿在画面里较短就判定坐姿的规则；旧模板的自动说明只描述可见关节，不再猜坐、走、插兜等动作。用户填写的动作说明优先。
  • 动作原图随模板备份、同步，左右翻转同时作用于原图参考和骨骼。旧模板仍可使用，但以前没有保存的原图无法自动恢复；如需保留手势、屈膝细节，请从原照片重新创建一次。
