Installation

  1. Download the APK

    Tap Download APK above in your phone’s browser. The file is named wardrobe-1.0.16-r1.apk.

  2. Allow installation

    Open the downloaded file. If prompted, allow your browser or file manager to install unknown apps, then tap Install.

  3. Set up an AI provider

    Accept the privacy policy on first launch. Under Settings › AI Services, select a provider, enter your API key, and test the connection. For AI try-on, add an image generation provider as well.

Verify the APK

Compare the downloaded file’s SHA-256 with the value above to verify its integrity.

# Windows
certutil -hashfile wardrobe-1.0.16-r1.apk SHA256
# macOS / Linux
shasum -a 256 wardrobe-1.0.16-r1.apk
