03 · 試穿

挑幾件衣服，看它穿在身上

選好模特和衣物，正面、側面、背面三個視角同時生成，每張都以模特同一視角的形象為底圖、以頭肩特寫為長相參考，三張圖裡的人和衣物保持一致。生成在後臺排隊進行，離開頁面也不會中斷。

資料就在你的裝置上

衣櫃是你的，資料也是

小衣櫃沒有自己的伺服器。衣物、照片和試穿記錄儲存在手機裡，想在多臺裝置上用，就同步到你自己的網盤。

本地優先

所有資料預設只在本機。解除安裝應用即刪除全部本地資料；也可以隨時匯出 zip 備份。

自帶 AI 服務

填寫你自己的 API Key，加密儲存在本機，不會被同步或備份。只有使用 AI 功能時，照片才會發給你選的服務商。

多端同步

谷歌雲盤、WebDAV（堅果雲、Nextcloud、群暉）、FTP/FTPS。改動後自動在後臺同步，換手機登入同一賬號即可。

FAQ

常見問題

小衣櫃收費嗎？

應用免費。AI 識別和生圖由你自己配置的服務商按量計費，費用取決於選用的模型；試穿頁會提示這次大約呼叫幾次影象模型。

開始使用需要準備什麼？

一臺 Android 8.0 及以上的手機，以及一個支援圖片輸入的對話模型（用於識別衣物）。想用 AI 試穿，再新增一個影象生成服務，例如豆包 Seedream 或通義千問影象。

我的照片會被上傳嗎？

小衣櫃沒有自己的伺服器。照片只在你使用 AI 功能時發給你配置的 AI 服務商；開啟雲同步後，資料同步到你指定的谷歌雲盤、WebDAV 或 FTP。

API Key 安全嗎？

API Key 用 Android Keystore 加密儲存在本機，不會被同步或備份。換新手機時，在「AI 服務」裡重新填寫一次即可。

有 iPhone 版嗎？

目前只有 Android 版。
