安裝步驟

  1. 下載安裝包

    在手機瀏覽器中點選上方的“下載 APK”，檔名為 wardrobe-1.0.16-r1.apk。

  2. 允許安裝

    開啟下載的檔案，系統提示時允許瀏覽器或檔案管理器“安裝未知應用”，再點“安裝”。

  3. 配置 AI 服務

    首次開啟同意隱私政策後，在「設定 › AI 服務」選擇服務商、填寫 API Key，點“測試連線”。想用 AI 試穿，再新增一個影象生成服務。

校驗安裝包

下載後可以核對 SHA-256，確認檔案完整、沒有被篡改：

# Windows
certutil -hashfile wardrobe-1.0.16-r1.apk SHA256
# macOS / Linux
shasum -a 256 wardrobe-1.0.16-r1.apk
