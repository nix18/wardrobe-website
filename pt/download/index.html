Instalação

  1. Baixar o APK

    Toque em Download APK acima no navegador do seu telefone. wardrobe-1.0.16-r1.apk.

  2. Permitir a instalação

    Abra o arquivo baixado. Se solicitado, permita que seu navegador ou gerenciador de arquivos instale aplicativos desconhecidos e, em seguida, toque em Instalar.

  3. Configurar um provedor de IA

    Aceite a política de privacidade no primeiro lançamento. Em Configurações › IA Services, selecione um provedor, insira sua chave API e teste a conexão. Para IA prova virtual, adicione um provedor de geração de imagem também.

Verificar o APK

Compare o SHA-256 do arquivo baixado com o valor acima para verificar sua integridade.

# Windows
certutil -hashfile wardrobe-1.0.16-r1.apk SHA256
# macOS / Linux
shasum -a 256 wardrobe-1.0.16-r1.apk
